# **App Name**: GameX Landing

## Core Features:

- Dynamic Sidebar: Responsive sidebar navigation with smooth transitions and icon highlighting.
- Animated Hero Section: Full-width hero banner with typing animation, decorative nature elements, and responsive scaling.
- Interactive Gallery: Responsive image grid that triggers login/signup modal on click.
- Game Highlights: Interactive cards displaying featured games that redirect to login/signup if the user is not logged in, via an API.
- Skill Challenges: Interactive quiz cards with login/signup modal triggered on click, managed via API.
- API Data Fetching: Fetch game-related data via API calls (e.g., /games) to enable future Node.js backend integration. Can use Firebase Auth + Firestore initially.
- Contact Form Submission: Submit contact form data (if present) via API, compatible with future backend integration.

## Style Guidelines:

- Primary color: Pastel green (#A8E6CF) to reflect the nature theme.
- Background color: Very light green (#F0FAF5), almost white, similar hue to the primary.
- Accent color: Soft sky blue (#B3E5FC) to complement the green and evoke environmental themes.
- Font: 'PT Sans' sans-serif for a modern, clean look, as requested.
- Rounded SVGs with nature-style colors (green, blue, yellow).
- Subtle nature-inspired animations, smooth transitions, and hover effects to enhance interactivity.
- Fully responsive layout from 320px to 1440px, ensuring seamless experience across devices.
